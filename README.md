## 👨‍💻 About Me

I'm a Senior Backend Engineer passionate about designing and building scalable, reliable, and maintainable backend systems.

My primary focus is backend development with **Node.js, Go, Microservices, and AWS**, with a strong interest in system architecture, distributed systems, and cloud-native engineering.

- 🏗️ **Architecture:** System Design, Microservices, Distributed Systems
- ⚡ **Backend:** Node.js, TypeScript, Go
- ☁️ **Cloud & Infrastructure:** AWS, Docker, Kubernetes, CI/CD
- 🔄 **Messaging & Caching:** Kafka, Redis, Event-Driven Architecture
- 🗄️ **Data & Storage:** PostgreSQL, MongoDB, Elasticsearch
- 🎯 **Engineering Interests:** High Availability, Scalability, Performance Optimization, Observability

I enjoy solving complex engineering problems, improving system reliability, and turning technical challenges into practical solutions.
